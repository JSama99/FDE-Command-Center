      Investigation receipt

      No verified receipt linkage for this Field Mission.

      Private investigation receipts exist offline, but none can be claimed as this mission's receipt. Stored receipts carry only the case identifier (case-001) — no mission, experiment, prediction, or assessment identifier — so sharing case-001 does not establish a receipt-to-mission relationship. This browser interface also has no read-only receipt endpoint (none is authorized under the current scope), so no receipt can be retrieved or integrity-checked here: receipt verification is unavailable through this interface.

      A linked receipt would report five independent facts separately — stored, integrity-checked, adjudicated, authorized, executed — and a stored hash alone would prove only that a stored file is unchanged, not that its investigation was accurate, independently validated, or causally correct. Pending adjudication stays pending.

      Future integration needs: record the mission and prediction identifiers in new receipts, plus a scoped read-only endpoint serving only the linked receipt. Stored receipts remain reviewable through the existing offline receipt command; authorized mission actions stay in the Field Mission.
