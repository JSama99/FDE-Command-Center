# CP-003.1 — Evaluation Scorecard

One sheet per participant (P1–P5). Score observed behavior during the
session, not post-hoc rationalizations. Behaviors (B) are objective;
opinions (O) are subjective — never average them together.

## A. Task scores (0 = failed/blocked, 1 = partial with help, 2 = independent)

| # | Task | B/O | Score | Evidence (quote or action) |
|---|---|---|---|---|
| T1 | Locate policy requirement + exact source offsets | B | /2 | |
| T2 | Identify stakeholder disagreement; label verified vs reported | B | /2 | |
| T3 | Compare H-ACK/H-QUEUE; state what would change each | B | /2 | |
| T4 | Lock prediction; state what reveal does/does not prove | B | /2 | |
| T5 | Distinguish proposed → approved → executed → verified | B | /2 | |

## B. Critical-error flags (check any observed)

- [ ] Called a hypothesis the root cause.
- [ ] Treated a stakeholder claim as verified fact.
- [ ] Treated approval as execution or remediation.
- [ ] Treated a Chaos Lab synthetic result as a real incident finding.
- [ ] Treated incomplete evidence as a confirmed miss.
- [ ] Misread a hash or metric as proof of truth.

Any flag triggers a debrief correction and weighs against GO.

## C. Comprehension and usefulness (1–5, opinion, with verbatim quote)

- Evidence classification clarity: /5 —
- Hypothesis comparison usefulness: /5 —
- Uncertainty handling: /5 —
- Decision-state clarity: /5 —
- Overall workflow usefulness: /5 —

## D. Next-step commitment (record exactly)

- [ ] Asked for a follow-up (quote): ___
- [ ] Named a real workflow they would apply it to: ___
- [ ] Introduced a colleague or sponsor: ___
- [ ] Discussed budget/payment: ___ (interest alone scores zero here)

occurred (e.g., "Chaos Lab Recovery tab — expected a fix button").
